# 星际 · INTERSTELLAR

基于“代码编织星河，粒子旋转成环”的描述制作的交互式粒子宇宙。采用原生 WebGL 与着色器，无需安装第三方包；手部识别模型已随项目保存，无需运行时联网下载。

## 打开项目

直接双击 `index.html`，即可离线体验。

如果需要本地 HTTP 预览，安装 Node.js 后在本目录运行：

```sh
node server.mjs
```

浏览器打开 <http://localhost:3000>。

**摄像头手势需要通过上述本地服务或 HTTPS 打开**，直接双击 HTML 时仍可使用鼠标和触屏控制。

## 玩法

- 拖动画面旋转视角；鼠标滚轮或触屏双指缩放。
- 双击或双点画面，释放一阵星尘。
- 控制台切换星环、旋涡银河、引力星团，粒子平滑变形。
- 调节 8,000–80,000 颗粒子、旋转速度、星光强度，切换冰川蓝、星云紫、落日金。
- 点击相机按钮导出不含控制台的 PNG 图片。
- 空格暂停/继续，F 进入/退出全屏。聚焦画布后，方向键旋转，+/- 缩放。
- 手机默认收起控制台，点击右下角“控制台”展开。
- 系统启用“减少动态效果”时，默认暂停流转；仍可手动播放。

## 手势控制（隐藏摄像头画面）

点击顶部的手掌图标，或控制台中的“手势控制”开关，允许浏览器使用摄像头。

| 手势 | 效果 |
| --- | --- |
| 张开手掌 | 粒子向外散开 |
| 握拳 | 粒子向中心聚拢 |
| 拇指和食指捏合并移动 | 旋转视角 |
| 两只手相互靠近或远离 | 缩小或放大宇宙 |

摄像头画面始终隐藏，页面只显示当前识别到的手势。识别在本机 Web Worker 中进行，摄像头帧不上传。关闭开关、切到后台或离开页面都会停止摄像头。浏览器自身的相机使用指示仍由浏览器管理。

面对摄像头，让手掌完整进入取景范围，保持光线充足。识别频率最多约 15 次/秒，避免阻塞粒子动画。若首次授权被拒绝，可在浏览器地址栏旁的权限设置中重新允许。

## 构建

```sh
node --check universe.js
node scripts/build.mjs
```

构建产物位于 `dist/`，可以部署到静态网站托管服务。无需安装第三方包。

## 主要文件

| 文件 | 用途 |
| --- | --- |
| `index.html` | 页面结构与控制台 |
| `styles.css` | 桌面和手机布局 |
| `universe.js` | 三种粒子几何、GLSL 着色器、形态插值、交互和图片导出 |
| `hand-controller.js` | 隐藏相机、手势分类、交互映射与相机生命周期 |
| `gesture-worker.js` | 后台手部关键点识别 |
| `assets/mediapipe/` | MediaPipe 1.1.1 运行库、WASM、手部模型与许可证 |
| `server.mjs` | 本地静态预览服务 |
| `scripts/build.mjs` | 生成静态部署产物 |

WebGL 不可用时自动切换 Canvas 轻量渲染，按所选密度抽样绘制最多约 16,000 颗主体粒子，以保持交互。手机或旧设备可降低粒子数量改善帧率。

本项目依据分享文案独立实现，未取得原视频画面，并非逐帧复刻。

手部识别基于 [Google MediaPipe Hand Landmarker](https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker/web_js)，运行库固定为 `@mediapipe/tasks-vision@1.1.1`。第三方运行库及模型按随附 Apache 2.0 许可使用；如需重新下载，可运行 `node scripts/download-hand-assets.mjs`。
